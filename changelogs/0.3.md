# `physu` 0.3.0 (Unreleased)

## Added
- Created `physu.energy` subpackage scaffold (`src/physu/energy/__init__.py`) and bumped package version to `0.3.0`.
- **`physu.energy.work`**: Added mechanical work and work-energy theorem formulas (`mechanical_work`, `net_work`, `gravitational_work`, `elastic_work`).
- **`physu.energy.kinetic`**: Added translational kinetic energy formulas (`kinetic_energy`, `kinetic_energy_from_momentum`, `speed_from_kinetic_energy`, `momentum_from_kinetic_energy`).
- **`physu.energy.potential`**: Added gravitational and elastic potential energy formulas (`gravitational_potential_energy`, `universal_gravitational_potential_energy`, `elastic_potential_energy`).
