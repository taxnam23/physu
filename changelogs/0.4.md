# `physu` 0.4.0 (Unreleased)

## Added
- Created `physu.thermodynamics` subpackage scaffold (`src/physu/thermodynamics/__init__.py`) and bumped package version to `0.4.0`.
- **`physu.thermodynamics.temperature`**: Added temperature scale conversions (`to_kelvin`, `to_celsius`, `to_fahrenheit`), `temperature_difference`, and thermal expansion (`linear_thermal_expansion`, `volumetric_thermal_expansion`).
- **`physu.thermodynamics.calorimetry`**: Added calorimetry formulas (`sensible_heat`, `latent_heat`, `specific_heat_capacity`, `equilibrium_temperature`).
- **`physu.thermodynamics.ideal_gas`**: Added ideal gas law solvers and kinetic theory formulas (`ideal_gas_pressure`, `ideal_gas_volume`, `ideal_gas_moles`, `ideal_gas_temperature`, `combined_gas_law`, `rms_molecular_speed`, `average_molecular_kinetic_energy`).
