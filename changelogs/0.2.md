# `physu` 0.2.0 (Unreleased)

## Added
- Created `physu.dynamics` subpackage scaffold (`src/physu/dynamics/__init__.py`) and PEP 561 `py.typed` marker.
- **`physu.dynamics.newton`**: Added Newton's second law (`force`, `acceleration`, `mass`), gravitational `weight`, and inclined-plane forces (`inclined_parallel_force`, `inclined_normal_force`).
- **`physu.dynamics.friction`**: Added static and kinetic friction formulas (`max_static_friction`, `kinetic_friction`, `friction_coefficient`, `normal_force`, `critical_incline_angle`).
- **`physu.dynamics.elasticity`**: Added Hooke's law and spring combination formulas (`spring_force`, `spring_force_magnitude`, `spring_constant`, `spring_displacement`, `series_spring_constant`, `parallel_spring_constant`).
- **`physu.dynamics.momentum`**: Added linear momentum, impulse, and 1D collision solvers (`linear_momentum`, `impulse`, `momentum_change`, `average_force`, `collision_velocities`, `elastic_collision_velocities`, `inelastic_collision_velocity`).
