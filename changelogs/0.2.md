# `physu` 0.2.0 (2026-11-16)

Adds classical dynamics (`physu.dynamics`), PEP 561 typing support, and runnable usage examples.

## Added

### Dynamics (`physu.dynamics`)
- **`newton`**: Newton's second law (`force`, `acceleration`, `mass`), gravitational `weight`, and inclined-plane forces (`inclined_parallel_force`, `inclined_normal_force`).
- **`friction`**: Static and kinetic friction (`max_static_friction`, `kinetic_friction`, `friction_coefficient`, `normal_force`, `critical_incline_angle`).
- **`elasticity`**: Hooke's law and spring combinations (`spring_force`, `spring_force_magnitude`, `spring_constant`, `spring_displacement`, `series_spring_constant`, `parallel_spring_constant`).
- **`momentum`**: Linear momentum, impulse, and 1D collisions (`linear_momentum`, `impulse`, `momentum_change`, `average_force`, `collision_velocities`, `elastic_collision_velocities`, `inelastic_collision_velocity`).
- **`gravitation`**: Universal gravitation and circular dynamics (`gravitational_force`, `gravitational_field_strength`, `orbital_speed`, `centripetal_force`).

### Typing, Examples & Tests
- Added PEP 561 `src/physu/py.typed` marker and exposed `physu.dynamics` at top level (`src/physu/__init__.py`).
- Added runnable scripts in `examples/` covering `units`, `constants`, `validation`, `kinematics`, and `dynamics`.
- Added unit tests in `tests/test_dynamics.py` (40 tests total across the suite), verified with `ruff` and strict `mypy`.

## Changed
- Replaced the inline Quickstart block in `README.md` with an `Examples` section pointing to `examples/`, and updated module documentation for `physu.dynamics`.
