# `physu` 0.1.0 (2026-11-16)

Initial public release of `physu` on PyPI (`https://pypi.org/project/physu/0.1.0/`).

## Added

### Core Infrastructure
- **`physu.units`**: Centralized `pint.UnitRegistry` (`ureg`), `Quantity`, `QuantityLike`, and normalization/conversion helpers (`to_quantity`, `check_dimension`, `convert_to`, `to_si`, `to_unit`) supporting `physu.ureg` quantities, external Pint registries, string expressions, and dimensionless scalars.
- **`physu.exceptions`**: Exception hierarchy with `PhysuError` and `PhysicalDomainError(PhysuError, ValueError)`.
- **`physu.validation`**: Dimensional and physical domain validators (`validate_quantity`, `require_non_negative`, `require_positive`, `require_non_zero`, `require_range`) checking `NaN`/finiteness, sign, zero constraints, and unit-aware bounds.
- **`physu.constants`**: Fundamental SI / CODATA 2022 constants bound to `physu.ureg` (`STANDARD_GRAVITY`, `GRAVITATIONAL_CONSTANT`, `SPEED_OF_LIGHT`, `PLANCK_CONSTANT`, `REDUCED_PLANCK_CONSTANT`, `ELEMENTARY_CHARGE`, `VACUUM_PERMITTIVITY`, `VACUUM_PERMEABILITY`, `BOLTZMANN_CONSTANT`, `AVOGADRO_CONSTANT`, `MOLAR_GAS_CONSTANT`, `STANDARD_ATMOSPHERE`, `ELECTRON_MASS`, `PROTON_MASS`).

### Kinematics (`physu.kinematics`)
- **`uniform` (MRU)**: `displacement`, `position`, `average_velocity`, `travel_time`.
- **`accelerated` (MRUA / SUVAT)**: `final_velocity`, `displacement`, `position`, `displacement_from_velocities`, `acceleration`, `torricelli_velocity`, `time_to_velocity`, `time_to_displacement`.
- **`vertical` (Free Fall & Vertical Throw)**: `vertical_position`, `vertical_velocity`, `free_fall_distance`, `free_fall_speed`, `free_fall_time`, `time_to_peak`, `max_height`, `time_to_height`.
- **`projectile` (2D Projectile Motion)**: `velocity_components`, `projectile_flight_time`, `projectile_max_height`, `projectile_range`, `projectile_position`, `projectile_velocity`.
- **`circular` (Uniform Circular Motion)**: `tangential_speed`, `angular_velocity_from_speed`, `centripetal_acceleration`, `period_from_frequency`, `frequency_from_period`, `angular_velocity_from_period`, `angular_velocity_from_frequency`, `period_from_angular_velocity`, `frequency_from_angular_velocity`, `angular_displacement`, `arc_length`.

### Packaging, Documentation & Tests
- Configured `pyproject.toml` (`hatchling` backend, Python `>= 3.10`, `pint>=0.23`), `LICENSE` (MIT), and `README.md`.
- Added 28 `pytest` unit tests across `tests/test_units.py`, `tests/test_validation.py`, `tests/test_constants.py`, and `tests/test_kinematics.py`, verified with `ruff` and strict `mypy`.
