# `physu` 0.8.0 (Unreleased)

## Added
- Created `physu.fluids` subpackage scaffold (`src/physu/fluids/__init__.py` and internal `_helpers.py`) and bumped package version to `0.8.0`.
- **`hydrostatics`**: Fluid density and specific gravity (`fluid_density`, `specific_gravity`), hydrostatic pressure (`hydrostatic_gauge_pressure`, `hydrostatic_pressure`), `pascal_hydraulic_force`, and `pressure_head`.
- **`buoyancy`**: Archimedes buoyant force (`buoyant_force`), `apparent_weight`, `floating_submerged_fraction`, and `submerged_volume_floating`.
- **`dynamics`**: Flow rates and continuity (`volumetric_flow_rate`, `flow_speed`, `mass_flow_rate`, `continuity_speed`), `dynamic_pressure`, `bernoulli_pressure`, and `torricelli_efflux_speed`.
- **`viscosity`**: `kinematic_viscosity`, `reynolds_number`, `poiseuille_flow_rate`, `stokes_drag_force`, and `stokes_terminal_velocity`.
- **`capillarity`**: `surface_tension_force`, `laplace_bubble_pressure`, and `capillary_rise_height`.

### Examples & Tests
- Added real-world fluid mechanics script [fluids.py](../examples/fluids.py) and updated `README.md`.
- Added unit tests in `tests/test_fluids.py` covering all five submodules, SI/non-SI unit conversions (`g / cm^3`, `L / min`, `gal / min`, `bar`, `atm`, `psi`, `cP`, `poise`, `cSt`, `stokes`, `mN / m`, `dyne / cm`), external Pint registries, and validation errors.
